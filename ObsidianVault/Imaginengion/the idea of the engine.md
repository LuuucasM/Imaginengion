the engine is very verbose like the language it was built in, zig. Entities, components, scripts, and events are the large drivers of the engine which means that to describe a given object you need to make the entity, add its component, set its component values, add the scripts. it is quite a process per entity. but then I want to build a like "layer" on top of the engine full of convenience functions so if you want a 3rd person character you can do AddEntity(3rd person character) and it will give you a reasonable default character. There will also be prefabs to help as well.
